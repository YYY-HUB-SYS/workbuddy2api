五种启动方式

0
0_panel.bat 推荐入口
选解释器 → 拉起 control_panel.py → 浏览器自动打开 http://127.0.0.1:8765。关掉它不会停网关。
1
1_3_install.bat
命令行安装向导：环境自检 → 写 config.json → 生成 4_run.bat / 4_run-hidden.vbs / 客户端配置.md。--dry-run 只演算不落盘，--uninstall 清理。
2
2_addaccount.bat
命令行加号：OAuth 设备码登录 → 落盘 auths/workbuddy-<uid>.json → 国内版自动每日签到。不会自动重启网关。
3
4_run.bat
前台启动：先杀掉占用端口的进程，再 wb2api.exe -config config.json，保留独立控制台窗口。端口号在安装时按配置写死。
4
4_run-hidden.vbs
后台启动：WScript.Shell 以 0 号窗口方式拉起 exe，输出写入 logs/gateway.log，面板负责 tail 该文件做实时回显。
解释器优先级统一为：runtime/python/python.exe → python → python3 → py。全都没有才会报错退出。

配置检视器

载入后可直接改端口与密钥，改完点「下载」覆盖本地 config.json，再回面板点「应用配置」并重启网关。

症状根因与处理
双击 bat 一闪而过runtime/python 被杀软隔离，或系统无 Python。把整个目录加白名单；面板里看「环境检查」项。
端口绑定失败7863 常被 Hyper-V / Docker 预留，改用 8080。面板①支持检测占用并一键结束进程。
加号成功但调用 404 / 无额度网关只在启动时读 auths/。加号后必须重启网关，或在②勾选「添加后自动重启」。
客户端连不上Trae / Cline 必须填局域网 IP，不能填 127.0.0.1；防火墙需放行该端口。
开机自启无效脚本写在 %APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\WorkBuddy2API-Autostart.vbs，仅当前用户生效。
探活一直失败看 logs/gateway.log 尾部。面板③会把该文件 tail 到页面底部执行日志区。
